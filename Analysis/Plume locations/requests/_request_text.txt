3.2  Cleaning the head track
Restrict to the arena. Drop head samples with x∉[0,580] or y∉[0,280], or non-finite coordinates. (Observed head coordinates run far outside the box; these are tracking artifacts and would otherwise create spurious distant bins.)
De-jump (recommended). Optionally remove isolated large frame-to-frame jumps (e.g. >Q px between consecutive kept samples, Q chosen data-drivenly, e.g. the 99.5th percentile of step size) before binning. Log how many samples each rule removes, per trial and overall.
Robustness check. Recompute the Loc-pooled odor field once using the BODY track instead of head; report qualitative agreement in the Task-1 report (one sentence + a supplementary correlation of the two mean maps). This guards against the cleaning choice driving the result.
3.3  Aligning ethanol to position (the two clocks)
For each trial, to attach an ethanol value to each kept head sample: eth_at_head = np.interp(head_time, ethanol_time, ethdeconv, left=np.nan, right=np.nan). Head samples whose time falls outside the sensor's coverage get NaN and are excluded from binning/statistics. Never resample the position clock onto the sensor clock — always bring the signal to the position samples.

4.  Task 1 — Odor-field statistical maps (per end location)
For each of the six end locations (Loc1–Loc6), build a spatial “odor field” from the deconvolved ethanol encountered along the animals' head trajectories, and summarize the odor distribution overall and per location. anotherLoc is summarized separately (§4, last paragraph), not turned into one of the six fields.
4.1  Binning rule (operationalizing “smallest bins with ≥3 observations”)
Fixed grid. Square bins of edge L px tiling the fixed arena extent x∈[0,580], y∈[0,280]. The SAME grid is used for all four panels of a location.
Choose L per location. Scan a descending candidate list (default L ∈ {40, 30, 25, 20, 15, 10} px). Pick the SMALLEST L for which at least 60% of visited bins (bins containing ≥1 sample from ≥1 trial) have ≥3 contributing trials. If no L reaches 60%, fall back to the coarsest (40 px) and note it. Record the chosen L and the coverage fraction for each location.
Mask sparse bins. In the max/mean/min maps, any bin with <3 contributing trials is set to NaN (not plotted / not stored as a value). The count map shows the true per-bin trial count including <3.
Observation = trial. A trial contributes to a bin if ≥1 of its cleaned, time-aligned head samples falls in the bin. The per-bin trial count is the number of distinct such trials.
4.2  Per-bin statistics
For every bin, pool the aligned ethdeconv values of all samples (across all contributing trials) falling in that bin, and compute: 
Maximal ethdeconv in the bin.
Mean ethdeconv in the bin.
Minimal ethdeconv in the bin.
Count = number of distinct trials contributing to the bin.

4.6  Task-1 hypotheses / acceptance (for the planner and auditor)
H1 (sparseness). H1: odor is spatially sparse — a minority of visited bins carry most of the odor mass. H0: odor mass is spread uniformly across visited bins. Test: concentration index vs. a uniform-map null. Accept if the index is reported per location with the null comparison, regardless of direction.
H2 (distance dependence). H1: mean/max bin odor decreases with distance from the endpoint. H0: no distance relationship (slope = 0). Test: per-location fit + CI; pooled mixed/animal-aware summary. Accept if slope + CI reported per location and pooled; a null/positive slope is a valid reported result.
H3 (trajectory structure). H1: trajectories fall into distinguishable types differing in odor encountered (e.g. tortuosity correlates with number/spread of encounters). H0: no association. Test: correlation/grouping of trajectory metrics vs. encounter metrics, per location. Accept if the association is quantified with an effect size and CI; direction reported before significance.

5.  Task 2 — Enhance the ethanol signal (recover distal encounters)
Goal: separate genuine ethanol encounters (brief, stereotyped transients) from the sensor's slow baseline drift, and use the statistical structure and temporal shape of high-SNR encounters near the endpoint to recover small-amplitude encounters far from the source. Operate per trial on the /behavior ethanol trace.
5.1  Recommended enhancement pipeline (default; substitutable per §5.3)
Drift removal. Estimate the slow baseline of each raw ethanol trace (e.g. a long rolling low-percentile window, ~10–30 s, or an asymmetric-least-squares baseline / high-pass) and subtract it → a drift-corrected trace. Justify the window from the drift timescale in the data. Keep ethdeconv available as an alternative input.
Template of a known encounter. Identify high-SNR encounter epochs NEAR the endpoint: head within a stated distance of the endpoint AND drift-corrected signal clearly above baseline (e.g. > per-trial threshold or > k·MAD of a quiet segment). Extract fixed-length windows around each such peak, align to the peak, and average → a canonical encounter template (its temporal shape). Build the template pooled and/or per location; state which.
Enhancement by matched filtering. Normalized cross-correlation of the drift-corrected trace with the template boosts template-shaped transients and suppresses drift and white noise → the enhanced trace. (A defensible wavelet/optimal-filter variant is acceptable.) The enhanced trace is the primary Task-2 signal product.
Encounter detection, matched fairly. An encounter = a threshold crossing (with peak prominence and a minimum inter-encounter refractory gap, e.g. 0.1–0.5 s, to avoid double-counting). Detect BEFORE (on the drift-corrected raw or ethdeconv) and AFTER (on the enhanced trace). Calibrate the two detectors so they share a matched false-positive rate on a quiet, far-from-source baseline segment — so the “after” gain reflects real recovery, not a looser threshold. State both thresholds and the calibration.
5.2  Operational definitions
Distance / “at a distance.” Distance = Euclidean head-to-endpoint distance (px) at each time. “Distal” = beyond a stated cutoff (default: > median head-to-endpoint distance for that trial, or a fixed px cutoff justified from the data).
SNR of an encounter. peak amplitude ÷ local baseline noise (MAD of the trace in a nearby quiet window). Define once and apply identically before/after.
“Most improved SNR at a distance.” For each trial, the mean SNR gain (after − before, or after/before) of its DISTAL encounters. Rank trials by this quantity; the top 10 populate the example figure.
Encounter count (for the scatter). Per trial, the number of detected encounters before vs. after enhancement, using the §5.1(4) detectors.
5.3  Deliverables
Figure A — 10 before/after examples. The 10 trials with the most improved distal SNR. Each panel overlays the before trace and the enhanced (after) trace on a common time axis, marks detected encounters, and annotates the head-to-endpoint distance context and the SNR gain. Save PNG+PDF to Analysis\Plume locations\reports\figures\enhancement as enhance_examples.png/.pdf.
Figure B — encounter-count scatter. One point per trial: x = # encounters detected BEFORE, y = # AFTER; include the identity line and report how many trials gain/lose/tie. Save as enhance_count_scatter.png/.pdf in the same folder. .txt sidecars name the source result file.
HDF5 — enhanced data. Write ONE well-annotated file Analysis\Plume locations\data\enhanced_ethanol.h5. Per-trial group /trials/<ttt> (0-padded, matching the aggregate) holding: enhanced (Ne,), its time (Ne,), baseline (Ne,), detected contacts before & after (contacts_before_idx/_time/_amp, contacts_after_…), and the tracked path (head (Nh,2), head_time, body (Nb,2), endpoint (2,)). Group attrs: n encounters before/after, distal SNR gain, chosen thresholds. Root attrs: method + all params (drift window, template length, refractory gap, distance/SNR definitions), source aggregate path, created_utc, generator, and a README attr. gzip4+shuffle; .tmp→os.replace; build_complete=1 last.
5.4  Task-2 hypotheses / acceptance
H4 (recovery). H1: enhancement increases the number of detected encounters, disproportionately for distal encounters. H0: no net increase at matched false-positive rate. Test: paired before/after counts across trials (Wilcoxon), split by distance. Accept if counts are reported with the matched-FPR calibration and the distal-vs-proximal split.
H5 (no fabrication — guard). The enhancement must not manufacture encounters from noise. Acceptance criterion (auditor checks): on a quiet, far-from-source baseline segment, the AFTER detector's false-positive rate is ≤ the BEFORE detector's. If it is higher, the result FAILS and the threshold must be recalibrated. Report the measured baseline FPRs.

8.  Notes, gotchas, and things NOT to do
Do NOT use the trial loc or duration attrs (both NaN). End location = file_name token; duration = time-base span.
Do NOT feed raw out-of-arena head coordinates into binning — clean to [0,580]×[0,280] first, or bins explode to px like −607/929.
Do NOT assume threshold applies to ethdeconv — its scale (≤0.65) matches raw ethanol (≤1.0), not ethdeconv (≤0.14). Verify at plan time.
Do NOT resample the position clock onto the 500 Hz sensor clock — bring the signal to the head samples via np.interp with NaN fill outside coverage.
Do NOT let Task 2's “after” detector run looser than “before” — match false-positive rate on a quiet baseline, or the count gain is meaningless.
Sensor values are uncalibrated a.u., single cohort, infrared only (114 trials). State these scope limits in both reports; do not generalize beyond them.
